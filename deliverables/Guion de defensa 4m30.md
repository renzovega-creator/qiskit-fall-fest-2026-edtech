# Guion de defensa · 4 minutos 30 segundos

La presentación funciona como demo visual completa; no requiere abrir la web ni
usar una computadora durante la exposición. Los tiempos suman 4:30. La página
pública queda para que el jurado la explore después.

| Diapositiva | Tiempo    | Qué contar                                                                                                                                                                                                                                                                                     |
| ----------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1           | 0:00–0:10 | Presentamos QuantumShot: aprender computación cuántica conectando ideas de estadística y machine learning con Qiskit.                                                                                                                                                                          |
| 2           | 0:10–0:35 | Muchos estudiantes pueden entender estadística clásica, pero les cuesta dar el salto a circuitos y mediciones. QuantumShot parte de ese conocimiento y propone microprácticas. El público de 16 años en adelante y el hábito diario son hipótesis que todavía debemos validar con estudiantes. |
| 3           | 0:35–0:55 | La web convierte el curso en una ruta. En lugar de presentar muchas opciones a la vez, muestra un siguiente paso y explica qué se desbloquea después.                                                                                                                                          |
| 4           | 0:55–1:20 | Empezamos con la regla de Born. El estudiante mueve el ángulo del qubit, predice la probabilidad de obtener uno y la compara con la visualización. La idea se aprende manipulando el concepto.                                                                                                 |
| 5           | 1:20–1:45 | Luego conectamos el error de Monte Carlo con la medición por shots. Al aumentar las muestras, la estimación se estabiliza y el error típico disminuye como uno sobre la raíz de N.                                                                                                             |
| 6           | 1:45–2:10 | En machine learning, comparamos el kernel RBF con un kernel cuántico sobre los mismos datos. El mapa permite ver qué cambia al variar la escala. Lo presentamos como una comparación para explorar, no como una ventaja cuántica demostrada.                                                   |
| 7           | 2:10–2:35 | El estudiante también escribe Python con Qiskit y ejecuta fragmentos para inspeccionar resultados y errores. La versión local ejecuta estas mediciones; la corrección automática por casos requiere Linux o macOS.                                                                             |
| 8           | 2:35–2:55 | El mapa organiza las habilidades y muestra cómo se conectan las ideas clásicas con las cuánticas. Cada misión convierte una habilidad en una meta concreta.                                                                                                                                    |
| 9           | 2:55–3:25 | Una misión se recorre en cuatro pasos: predecir, experimentar, observar y demostrar. Por ejemplo, ajustar un circuito para obtener uno con una probabilidad objetivo. Qiskit corre en un simulador; no afirmamos usar hardware cuántico.                                                       |
| 10          | 3:25–3:50 | Al completar retos, el portafolio reúne evidencias, resultados y código reproducible. El perfil de ejemplo deja ver cómo podría presentarse ese progreso, sin confundirlo con una certificación.                                                                                               |
| 11          | 3:50–4:10 | La portada añade un reto diario y preguntas de repaso espaciado. En local, el reto se mide con Qiskit; el perfil público utiliza resultados ya calculados.                                                                                                                                     |
| 12          | 4:10–4:30 | La demo completa se presenta aquí en las diapositivas. Después, el jurado puede recorrer GitHub Pages en el enlace de la pantalla: es una publicación estática con el curso y el perfil de ejemplo. La versión local ejecuta Qiskit.                                                           |

## Antes de presentar

- Ensayar con cronómetro y recortar cada sección al tiempo indicado.
- Dejar el enlace de Pages visible en la última diapositiva y compartirlo
  también en la descripción o el material del evento, si existe.
- Si preguntan por los resultados, aclarar que Qiskit usa simulación y que los
  resultados del perfil público son precomputados.
