QuantumShot

Privacidad de la demo pública

Este aviso describe la versión actual de QuantumShot en GitHub Pages y el servidor local incluido en el proyecto. La demo pública no tiene cuentas ni un servicio remoto que ejecute Python.

Lo que se guarda en tu navegador

El progreso, las preferencias de tema y paleta, el código que escribes en los ejercicios y tus reflexiones se guardan en el almacenamiento local del navegador (localStorage). Permanecen en ese navegador y no se sincronizan con una cuenta. Puedes borrarlos eliminando los datos de este sitio desde los ajustes del navegador.

La demo de GitHub Pages

GitHub Pages entrega archivos estáticos. Las actividades disponibles funcionan en el navegador y el perfil de ejemplo usa resultados precalculados; no se ejecuta código Python ni se ofrece inicio de sesión. En el editor puedes leer y cambiar el código, pero los botones de ejecución están desactivados y el código no se envía.

GitHub aloja esta web y procesa las solicitudes necesarias para servirla. Consulta el aviso de privacidad de GitHub para saber cómo trata los datos de uso de sus servicios.

La versión local

Si inicias tools/serve.py en tu equipo, el editor envía el código a 127.0.0.1 para ejecutarlo allí. Ese servidor escucha solo en tu equipo; el código no se envía a un servidor remoto de QuantumShot. El progreso sigue guardado en el navegador y no se sincroniza.

Para preparar y ejecutar la versión local, sigue las instrucciones de desarrollo.
