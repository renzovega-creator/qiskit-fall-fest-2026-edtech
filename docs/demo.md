# Recorrido de la demo pública

Abre
[la primera misión](https://renzovega-creator.github.io/qiskit-fall-fest-2026-edtech/juego.html#mision=m1).
La demo consulta resultados que ya calculó Qiskit. No requiere servidor, cuenta
ni computadora local con Python. Cambiar los controles selecciona el resultado
correspondiente; repetirlos devuelve el mismo dato.

1. **La moneda cuántica:** predice **50** unos, mueve el ángulo a **60°**, pulsa
   **Ver resultado de ejemplo** y luego **Comprobar el reto**. La probabilidad
   teórica es 25 %. Primero puedes medir con 90° para mostrar un intento que no
   cumple el objetivo y después corregirlo.
2. **Cazar el ruido:** predice **500** shots y selecciona **500**. Consulta el
   resultado y comprueba el reto. El error típico es menor que 0,02 sin superar
   el presupuesto de 600 shots.
3. **Detector de parecidos:** predice escala **media**, elige **1,5** y **una
   capa**. Consulta el mapa de clasificación y comprueba el reto.
4. **El kernel con ruido:** cuando las dos misiones anteriores estén completas,
   predice y selecciona **300** shots. Consulta las dos nubes de resultados y
   comprueba el reto de transferencia.
5. Abre **Demuestra**: el mapa, las insignias y las evidencias reflejan ese
   recorrido. Las evidencias indican que usan datos precomputados, también en el
   enlace compartido.

Para enseñar directamente un portafolio lleno, abre el
[perfil de ejemplo](https://renzovega-creator.github.io/qiskit-fall-fest-2026-edtech/juego.html#ejemplo).
El reto diario también admite una predicción y devuelve un resultado de ejemplo.
El editor permite leer y modificar el código; su ejecución necesita la versión
local. Durante la presentación de 4:30, las diapositivas muestran el recorrido;
el jurado puede explorar estos enlaces por su cuenta.
